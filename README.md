### 🧮 Calculadora em React

Este projeto foi desenvolvido durante o curso React Developer da DIO, com o objetivo de praticar os conceitos fundamentais do React. A proposta era construir uma calculadora funcional, mas optei por adaptar a solução com algumas diferenças em relação ao modelo do professor:

🔧 Tecnologias utilizadas

React.js – para a construção da interface e gerenciamento do estado.

CSS puro – em vez de styled-components, utilizei CSS tradicional para estilização.

Math.js – biblioteca utilizada para simplificar os cálculos matemáticos, tornando o código mais enxuto e fácil de manter.

🚀 Diferenciais da minha versão

Escolha pelo CSS puro, mostrando flexibilidade e domínio de diferentes formas de estilização.

Uso da biblioteca Math.js, que permitiu simplificar operações matemáticas e reduzir a complexidade do código.

Estrutura organizada, fácil de entender e expandir.



📂 Como executar o projeto
# Clonar o repositório
git clone [https://github.com/Mvnx-debug/calculadora-curso-DIO.git](https://github.com/Mvnx-debug/calculadoraReact)

# Entrar no diretório
cd calculadora-curso-DIO

# Instalar as dependências
npm install

# Executar o projeto
npm start
